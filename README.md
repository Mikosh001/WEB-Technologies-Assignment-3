# Discover Mangystau

A five-page responsive travel guide to Aktau and Mangystau by Berdibek Meiirbek. This is the Midterm Project for web technologies.

## Links

- [Live website](https://mikosh001.github.io/WEB-Technologies-Assignment-3/)
- [GitHub repository](https://github.com/Mikosh001/WEB-Technologies-Assignment-3)

## Pages and features

- `index.html` — home page with an introduction and featured places.
- `region.html` — why Mangystau is the chosen topic, with text and a list.
- `places.html` — four featured places and a comparison table.
- `gallery.html` — a nine-photo CSS Grid gallery.
- `plan.html` — a form that validates input and displays a personal plan on the page. It does not send or save information.

Every page has a shared Bootstrap navigation bar. The project uses semantic HTML5, custom CSS, Flexbox, CSS Grid, Bootstrap's responsive grid and utilities, positioning, and tablet/mobile media queries. Bootstrap 5.3.8 CSS and JavaScript are included locally under `assets/bootstrap/` so the site also works without a CDN.

## Run locally

Open `index.html` in a browser. The site is static and needs no build step or server. Use the navigation bar to open the other pages.
